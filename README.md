# Portfolio

The personal portfolio website of Rohan Hasan Khan Orko, a first-year Computer Science student interested in backend development, competitive programming, and game development.

## Included sections

- About, skills, current focus, and goals
- Featured project pages for Chronosync, The Last Train Home, and CNG
- A lightweight timeline and résumé placeholder
- Future navigation for GitHub, itch.io, Codeforces, and LinkedIn
- Persistent dark/light colour preference

## Run locally

This is a static site with no dependencies.

```powershell
cd portfolio
Start-Process index.html
```

## Project structure

```text
index.html                 Main portfolio page
projects/                  Focused pages for featured projects
style.css                  Responsive styles and colour themes
script.js                  Theme preference and small enhancements
REPOSITORY-METADATA.md     Suggested GitHub configuration
```
